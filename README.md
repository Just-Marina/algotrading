# 📈 Algotrading/ Quant research: оптимизация портфеля и стратегии против индекса RTS

> **Собственный ML-фреймворк для отбора прибыльных инструментов и автоматизации торговой стратегии с минимальным риском.**
>
> **Результат:** +30% доходности за 7 месяцев против −15% у RTS, drawdown < 10%, автоматический отбор 5 лучших инструментов из 45+.

---

## 🚩 О проекте

**Цель:**  
Построить торговую стратегию, которая стабильно обгоняет индекс RTS на исторических данных, при этом риски (просадка и волатильность) минимизированы через оптимизацию параметров и диверсификацию портфеля.

**Кому полезно:**  
ML/Quant-специалистам, кто хочет быстро бэктестить и оптимизировать стратегии для разных рынков (может быть использовано как стартовый фреймворк для финтеха).

---

## 🔎 Кратко: как работает стратегия

1. **Сбор данных:**  
   - Исторические котировки из MetaTrader 5 по всем доступным инструментам брокера
   - Отбор инструментов со спредом ниже заданного уровня

2. **Фич-инженеринг:**  
   - Классические технические индикаторы (TA-Lib)
   - Кастомный индикатор сезонности (расчет сезонных колебаний за периоды 2–3 года, месячные паттерны)

3. **ML/Стратегии:**  
   - Протестированы две модели: регрессия и классификация (финально выбрана классификация — сигналы Buy/Sell)
   - Для каждой модели подбирались гиперпараметры, итоговые параметры усреднялись для устойчивости

4. **Отбор инструментов:**  
   - Бэктест по каждому активу с расчетом доходности, max drawdown, Sharpe
   - Оставлены топ-5 инструментов с лучшим risk/reward (CRRA-оптимизация, кастомная функция на базе ряда Тейлора)

5. **Оптимизация портфеля:**  
   - Финальное распределение весов портфеля (см. ниже)
   - Настройка Money Management: оптимизация take profit, stop loss и кредитного плеча по Sharpe Ratio

6. **Сравнение с RTS:**  
   - Итоговая стратегия уверенно обгоняет RTS даже в убыточный для индекса период
